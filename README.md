# Mars Round Trip

Occupy Mars. Simple.

A side-on SpaceX-style rocket game: launch from Starbase, mine asteroids in low Earth orbit, fly the trans-Mars injection burn, land at Jezero, drive the rover to refine fuel, grow a Mars colony, and fly home to a tower catch.

The whole game is a single `index.html` with no build step. Netlify serves it as-is (`netlify.toml`).
